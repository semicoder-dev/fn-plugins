# 模型目录 0.2.0

适用于 Fn 0.7 应用平台，使用公开 SDK 0.6.0 和 Fn UI 0.1.0。

- 通过 models.dev 公开 JSON API 查询模型，无需 API Key。
- 搜索、机构/类型/输入模态/能力筛选、排序分页；查看模型规格、供应商报价、缓存价格与阶梯条件。
- 一小时按需缓存、手动刷新、失败保留旧数据，关闭应用取消网络请求。

在 Fn「应用」中心刷新官方市场，安装「模型目录」。无需更新 Fn；翻译、笔记、看板继续使用原 0.2.0 归档。目录只供查阅，不增加模型连接或改变 ChatGPT 订阅调用范围。上游未提供的价格显示 `—`；额外与阶梯费用保留上游字段，实际收费以供应商为准。

此包采用 Fn 0.7 应用契约，旧模型目录插件归档不适用于当前宿主；无旧数据迁移或删除。官网使用说明：https://semicoder.dev/fn/docs/models。
