# 看板与模型目录 0.1.1

适用于 fn 0.6 / SDK 0.5.0。在应用中心检查更新并分别更新已安装插件，无需更换 fn 应用或重新配置数据。

- 看板：收紧新建、重命名、筛选、卡片详情、标签和归档弹窗的重复留白；修复无匹配标签仍保留空列表间距，以及标签弹窗关闭后的焦点返回。
- 模型目录：统一价格详情的段落和价格分组间距。
- 两个插件的后端、数据格式、共享 UI 和依赖契约不变；现有看板内容和目录缓存保留。fn 0.6.1 可在空闲时局部更新，无法安全热更新时沿用宿主恢复流程。

验证：仓库与仓库外冻结安装/检查、24 测试/110 断言、打包；公开 fn 0.6.1 隔离更新与完整数据/epoch 保留；浏览器明暗、560px、焦点/菜单和滚动可达；原生看板弹窗与菜单验收。详细范围见两个插件的 acceptance.md。
