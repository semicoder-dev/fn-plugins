# Fn 应用 0.3.0

翻译、笔记、看板、模型目录统一适配 Fn 0.8 / hostApi 2，精确消费 SDK 0.7.0 和 UI 0.2.0。

- 翻译展示最近译文，笔记展示数量和最近内容，看板展示统计和待办概览；模型目录使用默认描述行。
- 独立页面数据通知与摘要解耦，看板多视图同步和重连读取保留；摘要发布失败不影响已提交的业务结果。
- 删除旧小组件清单和 API。请先安装 Fn 0.8 完整 DMG，再在应用中心更新应用；沿用原应用身份和业务数据，无需清空数据库。
- CI 增加仓库外冻结安装/检查/测试/打包，正式发布拒绝本地路径依赖与 overrides，行情示例纳入检查及打包。
