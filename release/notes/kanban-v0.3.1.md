# 看板 0.3.1

适用于 Fn 0.8 的 hostApi 2，使用公开 SDK 0.7.1 / Fn UI 0.2.1 构建。

- 修复卡片标题、标签色条和看板入口的重复边框及标签周围多余空白。
- 列表名称、列表菜单与添加卡片恢复简洁样式，保留键盘焦点提示。
- 包含 Fn UI 0.2.1 的输入与按钮单层焦点边框修复。

在 Fn 应用中心点击「检查更新」，更新看板即可，无需重新下载 Fn。运行中更新会先关闭看板，请先保存未提交内容；看板、卡片、标签和偏好数据保留。

本次仅更新看板，翻译、笔记、模型目录、Fn 宿主及 SDK/UI 不发布新版本。

使用说明：https://semicoder.dev/fn/docs/plugins。
