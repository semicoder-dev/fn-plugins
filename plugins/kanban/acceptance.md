## 自动检查

- `bun run check`：包契约、固定开发归档 SHA-256、TypeScript strict、格式检查。
- `bun run test`：7 项 / 28 断言，覆盖 SQLite 恢复、顺序与详情、归档父级约束、并发冲突、请求去重、写入失败事务回滚、日期与输入校验、未来数据库版本拒绝、Cordis API 释放和重新启用。
- `bun run pack`：后端 TypeScript、浏览器模块、CSS、包内 SVG；共享 React/Cordis/FIA/SDK 使用 peer，不打进插件归档。
- 干净临时目录独立冻结安装、检查、测试和打包，无相邻宿主源码依赖。
