# 网络搜索（本地开发版）

通过 fn 宿主 Agent loop 搜索、阅读网页并总结，支持插件页面与 fn Chat。插件 ID `web-search`，初始版本 `0.1.0`；未发布或上架，公开 fn 0.4.5 / SDK 0.3.5 不具备所需接口。

## 构建和安装

在 fn-plugins 仓库根目录执行：

```sh
bun install --frozen-lockfile --ignore-scripts
bun run check
bun run test
bun run pack
bun run index:check
```

生成 `artifacts/web-search-0.1.0.tgz`。在包含 Agent loop 与 fn Chat v2 的开发宿主中，打开「应用中心 → 从地址安装 → 选择本地包」安装该归档。安装任务成功后出现「网络搜索」页面。

当前三个开发插件及根构建工具统一消费 `vendor/agent-sdk.tgz`，来源和 SHA-256 见 `vendor/agent-sdk.json`。归档包含 SVG 图标、Agent/Chat，自包含且不依赖相邻宿主源码；两个已发布的 0.1.2 归档仍使用公开 SDK 0.3.4。首次公开发行前需切换已验收的公开 SDK、补齐发行流程并验证真实模型与 Chat 客户端，不能直接上架本地候选条目。

## 页面使用

选择已配置的模型，输入问题并开始。宿主会执行最多 8 个模型步骤，9 分钟超时；模型按提示搜索并读取相关网页。结果保留实际工具来源，区分已读正文、部分正文和仅搜索摘要。模型回答并非逐项事实校验，检索失败或来源不足会明确显示。

历史包括页面和 Chat 发起的话题。选中话题后追问；切换模型先新建话题。可停止运行、复制答案和来源、删除空闲话题。页面关闭不会停止任务，重新打开按宿主记录恢复。答案下方只展示本轮工具来源，去重后最多 30 条，Chat 回复最多附 10 条；不会把上一轮天气链接混到新闻答案下。重启中断的任务不自动重做。

每轮按宿主当前时间重新检索。默认不限定网站或搜索收录时间，空结果会按提示放宽条件；动态网页没有正文或超时后换来源。检索过程显示实际查询与结果数量，工具错误和无来源提示直接显示在答案下方。抓取成功不代表每项事实已核实，实时数据仍以来源为准。

搜索引擎可能要求人机验证。兼容开发宿主会明确报告引擎不可用，插件可转到公开新闻栏目等其他来源，答案说明覆盖范围；不绕过验证码。更新研究策略后，新话题使用新提示，已有话题仍保留原上下文与系统提示。

## fn Chat

前提是 fn 宿主已配置 Chat v2 同步并在线，聊天客户端连接到该宿主。安装后自动提供「网络搜索」机器人，无需修改 iOS/Mac 客户端或部署新 CloudKit schema。

- 首次发送问题时，如果没有有效默认模型，机器人发送原生模型选择卡片；选择后继续原问题。模型也可在插件页面选择并保存。
- 后续文字在同一 Agent 话题中追问；`/新话题` 清除当前关联，下一条问题创建新会话；`/模型` 重新选模型；`/帮助` 查看用法。
- 搜索进度使用 Chat delivery，不逐 token 发消息；完成后发送答案和实际来源，长文本按协议上限分段。
- Chat 按会话串行处理，搜索期间的新文字排队。需要中止时，在宿主页面找到对应话题并点击「停止」。账号切换、Chat 超时或宿主退出会向 Agent 传递取消。
- 模型卡片和会话关联存入插件 KV；旧卡片、跨会话回复和不可用模型不能启动搜索。修改模型会开始新话题。Chat 处理与 Agent 均不自动重放中断任务，未送达的最终回复可在页面查看结果。

## 验收

`bun run test` 包含参数/工具范围、追问、卡片、取消、来源安全及长文本协议测试。使用以下可选命令对指定宿主源码做独立归档安装与完整 Chat runner / Agent 集成验收：

```sh
bun scripts/verify-search-host.ts /path/to/fn
```

验收采用临时 SQLite 和模拟模型、网页、CloudKit 传输，不读取真实账号、不发送生产聊天。它覆盖卡片选择、检索/抓取/总结、结果来源、重复同步不重放及页面追问。真实 provider、实时搜索质量和手机/独立 Mac Chat 联机效果仍需实测。
